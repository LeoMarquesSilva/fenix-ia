## Resumo (texto curto para a vitrine)

Plataforma web para **organizar, redigir e reutilizar teses jurídicas** em um único acervo. Inclui **dashboard com métricas e filtros** (área, assunto, criador, datas), **editor de texto rico** (TipTap), **geração e auxílio com IA** (OpenAI) alinhado a linguagem jurídica brasileira, **importação** (Word, Excel) e **exportação para DOCX**. O acesso é **controlado por perfis** (admin, advogado, supervisor, estagiário) com autenticação via **Supabase**.

**Em uma linha:** acervo corporativo de teses com editor profissional, IA integrada e gestão de usuários.
